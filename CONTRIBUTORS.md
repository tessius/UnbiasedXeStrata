# Contributors

Unbiased XeStrata is built on the work of:

- **Robert Karl** ([robertkarl](https://github.com/robertkarl)): UnbiasedStrata, the repository and the engines this is built on.
- **MistVVK** ([MistVVK](https://github.com/MistVVK)): [XeStrata](https://github.com/MistVVK/XeStrata), whose SYCL matrix tiles
  (`sycl-poly/src/xe/`) give the Intel prompt path its speed.
- **Project Maya** ([alesha-pro](https://github.com/alesha-pro/maya-inkling-mini)): the Inkling-2-Mini engine (`src/ik2/`, UnbiasedStrata's `strata-ik2`) that `sycl-ik2/` migrates.
- **Tessius** ([tessius](https://github.com/tessius)): the `strata-poly` port to SYCL, the `strata-ik2` port (`sycl-ik2/`), their fixes, Intel-specific kernels, tests and documentation.

Further credits (Strata, PolyStrata, llama.cpp/ggml, Intel, the model makers) and the licenses: [`sycl-poly/CREDITS.md`](sycl-poly/CREDITS.md).
